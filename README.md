# 🎯 Number Guessing Game

An interactive web-based number guessing game built with HTML, CSS, and JavaScript. The application generates a number and allows the user to make guesses while providing feedback to improve the next attempt.

## ✨ Features

* Generates a random number
* Accepts user guesses
* Provides feedback for each guess
* Tracks the game interaction
* Simple and responsive user interface
* Reset/restart functionality

## 🛠️ Technologies

* **HTML5**
* **CSS3**
* **JavaScript**

## 🔄 How It Works

```text
Start Game
    ↓
Generate Random Number
    ↓
Enter Guess
    ↓
Compare Guess
    ↓
Display Feedback
    ↓
Continue or Restart
```

## 🚀 How to Run

1. Clone the repository:

```bash
git clone https://github.com/naveen057/number-guessing-game-web.git
```

2. Navigate to the project folder.

3. Open `index.html` in any modern web browser.

No additional installation is required.
